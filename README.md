# 🛼 Patinando Hacia El Futuro

Sitio web oficial y landing page de alto rendimiento de la **Escuela de Patinaje de Carreras Patinando Hacia El Futuro** (Caimalito · Pereira / La Virginia · Risaralda).

---

## 🌟 Características y Secciones

- **Hero Dinámico:** Presentación institucional con tipografía deportiva de impacto, llamada a la acción hacia WhatsApp y carrusel de estadísticas clave.
- **Nuestra Escuela:** Historia fundacional comunitaria por el líder Alfredo, enfoque social, fogueo nacional y carrusel fotográfico de alta velocidad.
- **Nuestros Profes:** Equipo técnico y formativo con tarjetas interactivas de borde animado neón (`rotateBorderBeam`) en orden institucional.
- **Nuestra Comunidad:** Concentrador digital y redes sociales oficiales (Instagram, TikTok, Facebook, WhatsApp) con borde animado continuo.
- **Nuestras Victorias:** Podio olímpico piramidal (Oro en el centro más alto, Plata a la izquierda y Bronce a la derecha) acompañado de galería fotográfica interactiva.
- **Próximas Competencias:** Calendario de pista y válidas departamentales/nacionales en orden de degradado con estados de inscripción y categorías.
- **Noticias & Comunicados:** Avisos oficiales, convocatorias, tecnificación y nuevos uniformes.
- **Footer Institucional:** Pie de página completo con acento neón en degradado institucional (`#E51B23` → `#F57C00` → `#FFD21F` → `#009B55`), enlaces de navegación y botón de contacto.

---

## 🎨 Paleta de Colores Institucional

La identidad visual está construida sobre un fondo negro puro (`#000000`) con el degradado continuo:

| Color | Hex | Representación |
| :--- | :--- | :--- |
| **Rojo Energía** | `#E51B23` / `#FF3B30` | Pasión, velocidad y fuerza atlética |
| **Naranja Velocidad** | `#F57C00` | Dinamismo, agilidad y juventud |
| **Amarillo Futuro** | `#FFD21F` | Triunfo, medallas de oro y esperanza |
| **Verde Pantera** | `#009B55` / `#00E676` | Disciplina, naturaleza y comunidad |

## 🚀 Tecnologías

- **Framework:** [Astro](https://astro.build/)
- **Estilos:** CSS3 nativo moderno, Glassmorphism, animaciones de borde con `conic-gradient`
- **Diseño Responsivo:** Mobile-first optimizado para celulares, tablets y pantallas de escritorio
- **Vista Autónoma:** Archivo `preview.html` listo para visualización directa sin servidor

## 🛠️ Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   cd TU_REPOSITORIO
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:4321](http://localhost:4321) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
